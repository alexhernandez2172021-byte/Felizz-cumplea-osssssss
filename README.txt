REGALO DE CUMPLEAÑOS PARA STEPHANY — 100 RAZONES 💗

Archivos:
- index.html: página principal.
- estilo.css: diseño y estilos.
- script.js: interacción de las 100 razones y sorpresas.

Para publicarlo en GitHub Pages:
1. Descomprime este ZIP.
2. Sube index.html, estilo.css, script.js y README.txt a la raíz de tu repositorio.
3. En GitHub, entra a Settings > Pages y confirma que esté publicado desde la rama correcta y la carpeta / (root).
4. Abre el enlace de GitHub Pages y prueba varios corazoncitos.

La sección de fotos fue reemplazada por 100 corazones interactivos. Cada corazón revela una razón distinta al tocarlo.
